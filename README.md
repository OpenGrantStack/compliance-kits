## 🧭 Purpose

Compliance Kits provide **reusable, versioned packs** that grant programs can adopt to meet transparency, audit, and regulatory expectations.

| Kit Type | Contents |
|----------|----------|
| **Policy Packs** | Model policies for conflict of interest, conflict disclosure, data handling, dual control |
| **Audit Checklists** | Pre-award, post-award, and close-out checklists |
| **Evidence Packs** | Templates for collecting and packaging audit evidence |
| **Jurisdiction Packs** | Starter mappings for common regulatory environments (extendable) |
